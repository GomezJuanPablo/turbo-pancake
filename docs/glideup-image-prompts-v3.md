# GlideUp — Image Generation Prompts (v3 · NE-Accurate)

Copy-paste ready for ChatGPT (GPT-4o image gen), DALL-E 3, or Midjourney. v3 palette matches the actual Next Experience workspace — midnight navy chrome, deep teal action color, magenta cosmic spark.

---

## 🎯 Logo Prompt

```
Design a modern minimal logo for "GlideUp" — a ServiceNow certification practice
platform.

The mark is a stylized capital letter G with an upward-curving glide trail
exiting from the bottom-right of the G and arcing up-and-right, suggesting
forward motion and "leveling up." The trail should feel light, fast, and
confident — like a comet tail.

Style: flat vector, geometric, clean, modern enterprise-software aesthetic.
Single mark only — no wordmark text.

Color: deep teal #0E8B9E as the primary fill of the G, with a small bright
magenta #E91E63 dot or spark at the top-right of the G (like a cosmic flare).
The glide trail fades from teal to a lighter highlight. Transparent background.

Must scale from 32px favicon to 200px header. Avoid: 3D effects, drop shadows,
stock corporate clip art, generic AI clichés, mascot characters, more than
three colors in the mark.

Output: square, centered, with breathing room around the mark.
```

## 🖼️ Banner Prompt

```
Design a wide hero banner image (1500x500px, web header proportions) for
"GlideUp.net" — a free community ServiceNow certification prep platform with
gamified learning. The banner should feel like the hero section of a Next
Experience workspace landing page.

Show the wordmark "GlideUp" in bold modern sans-serif (Inter Black or similar),
with the capital "G" featuring an upward-curving glide-trail mark exiting its
base. Below the wordmark, place the tagline "Level Up Your Now" in lighter
weight.

Background: deep midnight navy #1B1B3F with a subtle gradient to a slightly
warmer purple-navy #2A2A5C. Layered cosmic accents: a scattered starfield
(small white/pale dots of varying brightness), a few brighter sparks in deep
teal #0E8B9E and magenta #E91E63, and a soft teal radial glow off to one side
suggesting a distant nebula. Keep negative space generous so the wordmark
breathes.

Wordmark color: white #FFFFFF for "Glide", deep teal #0E8B9E for "Up". Tagline
in light cool gray #B8B8D1.

Style: modern enterprise-software-meets-cosmic-adventure. Sophisticated,
polished, suggests both seriousness (it's a real cert) and play (it's a
journey). Suitable as an OG/Twitter share card and site hero banner.

Avoid: stock photo people, generic tech-bro gradients, busy backgrounds,
low-contrast text, neon overload, AI-fingered hand artifacts, cartoonish
spaceships.
```

## Notes for use

- **Generate the logo first** — it locks the G mark for the banner.
- **Ask for 3–4 variations** of the logo before locking.
- **Banner second**, paste the locked logo into the prompt as a reference image if your tool supports image-input prompting.
- **Vector formats** — prefer SVG; fallback is 2048px transparent PNG run through Vectorizer.AI / Illustrator Image Trace / Inkscape trace-bitmap.
- **Color verification** — image-gen tools drift on exact hex. Sample the output and request color correction if `#0E8B9E` came back as something like `#1FA8B5`.
